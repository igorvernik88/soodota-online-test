# Анимации героев Судоты

Для каждого героя нужны пять прозрачных PNG-лент с кадрами в один горизонтальный ряд:

| Состояние | Имя для Дырокола | Имя для Шустрика |
| --- | --- | --- |
| Ожидание | `dyrokol-idle.png` | `shustrick-idle.png` |
| Бег вправо | `dyrokol-running.png` | `shustrick-running.png` |
| Атака героя или постройки | `dyrokol-attack.png` | `shustrick-attack.png` |
| Решение крипа или леса | `dyrokol-solving.png` | `shustrick-solving.png` |
| Празднование | `dyrokol-celebrate.png` | `shustrick-celebrate.png` |

Кадры одной ленты должны иметь одинаковую ширину. Прозрачное поле вокруг персонажа допустимо, но положение ступней должно оставаться одинаковым во всех кадрах и состояниях. Бег рисуется вправо: игра сама отражает его при движении влево.

Количество кадров может отличаться между файлами. После получения финальных PNG нужно измерить каждую ленту и заполнить `file`, `frames`, `frameMs`, размеры и точку опоры в `src/hero-animation.js`.

`celebrate` — одноразовая анимация. Её полная длительность равна `frames × frameMs`; движение героя не прерывает её.
