# Судота — версия 4

Перенос проекта через GitHub и запуск на другом компьютере: [docs/github-transfer.md](docs/github-transfer.md).
После клонирования сначала установите зависимости и выполните `npm run build`, чтобы получить `sudota.html`.

Откройте `sudota.html` или обновите уже открытую страницу. Автономная версия работает без сети. Обновление начинает новый матч с выбором героя.

## Личные цифры и навыки

Каждый герой начинает с 3 личными цифрами и навыками ранга 0. Раз в 120 игровых секунд приходит ещё одна цифра; таймер работает после смерти, но останавливается на паузе. Запас не ограничен, сохраняется после смерти, не продаётся и не передаётся. Цифра оплачивает мгновенный правильный ход или прокачку навыка: переходы 0→1→2→3→4 стоят 3/5/6/7 цифр. Навыки независимы от здоровья. Числа рангов в `src/config.js` помечены `[PLACEHOLDER]` и требуют плейтеста.

Круг в нижнем HUD показывает запас и прогресс; наведите курсор для оставшегося времени, нажмите для прокачки. Панель показывает текущий и следующий эффект каждого навыка. Боты сначала открывают все навыки, затем повышают их по кругу и резервируют стоимость следующего ранга.

Награды личного ресурса:

- Смерть вражеского крипа: 10 секунд прогресса делятся между живыми героями команды последнего удара в радиусе 150.
- Убийство героя: убийце 2 цифры; участники за последние 30 секунд делят 120 секунд прогресса. При добивании крипом или постройкой начисляются только ассисты. Денежные выплаты за героев сохранены.
- T1/T2/T3: каждому союзнику 1/1/2 цифры; завершение линии — ещё 1. Погибшие союзники тоже получают награду.
- Лес: 15 секунд за 4×4, 25 секунд за 6×6; монеты сохраняются.

Переплёты здоровья стоят 400 и 950 монет (улучшение с 6×6 до 9×9 — 550 до скидки). Волны по три крипа выходят каждые 40 секунд; добивание героем даёт 43 монеты. Постройки наносят крипам одну цифру раз в 2 секунды, выбирая менее повреждённых постройками. Атаки по героям и стан имеют отдельные таймеры. Заполненность крипов оставлена 8–11 из 16 клеток до проверки осады человеком.

Самолётик доставляет лопату; Правщик доставляет предметы. Правщик не заполняет обычные судоку, но может бесплатно решить собственную коробку. Разведка и доставка доступны без ранга навыка.

## Управление

ЛКМ — движение или открыть цель; 1–9 — перо; Пробел — одна универсальная цифра в выбранную клетку (удержание не повторяет ход); F1 — пауза; Escape — закрыть окно. Shift+ЛКМ по врагу — следование, но Shift+цифра и Shift+клик по клетке больше не расходуют цифры. N — заметки, B — лавка, M — обзор, F — камера за героем. Колесо — масштаб, ПКМ с перетаскиванием — камера. На паузе открытое судоку сохраняется.

## Быстрые правки

Прочитайте `AGENTS.md`. Команда `npm run context -- hud` покажет файлы, символы и подходящие проверки для выбранной области; без аргумента — список областей. `npm run context -- --find .action-bar` найдёт правила в порядке CSS-каскада.

`style.css` теперь содержит только импорты. Небольшие файлы в `styles/` сохраняют прежний порядок правил: базовые стили, адаптивные слои, затем текущие компоненты HUD. Меняйте найденное правило, не дописывайте новое переопределение в конец. Настройки конкретного героя находятся в `src/animations/<role>.js`, переключение состояний — в `src/hero-animation.js`. Сборщик получает перечень спрайтов из манифеста, а не ищет имена файлов в тексте кода.

## Архитектура

- `src/config.js`: параметры мира, герои, магазин, определения навыков и ранги.
- `src/progression.js`: личный ресурс, прогресс таймера, траты, ранги и порядок прокачки ботов.
- `src/sudoku.js`: генерация и логическое решение.
- `src/boards.js`: независимые страницы, пустые поля и фантомные подсказки.
- `src/combat.js`: крипы, атаки, HP, регенерация, возрождение и бекдор.
- `src/logic.js`: игровой цикл, покупки, доставка, навыки и решения ботов.
- `src/render.js`: Canvas-мир, камера, спрайты и попадание указателя; мини-карта в интерфейсе отключена.
- `src/animations/`: данные спрайтов по героям; `src/hero-animation.js`: состояния и отрисовка анимации.
- `style.css`: порядок подключения; `styles/`: исходные стили компонентов и адаптивные слои.
- `src/combat-ui.js`: здоровье, запросы и похвала.
- `src/ui/`: отдельные компоненты магазина, судоку, HUD и диалогов. `dom.js` обновляет существующие элементы, сохраняя фокус и клетки.
- `src/app.js`: управление, состояние открытых панелей и цикл отображения.

Выбор листа меняет представление, а не переносит прогресс. Задание лопате хранит номер страницы. HP и постройки используют одинаковый механизм ручного ввода, автоматические попадания обрабатывает боевая система. Сборка через esbuild разрешает импорты, объединяет модули и минифицирует итог. Исходники остаются отформатированными. Обновление HUD ограничено 10 разами в секунду; анимации карты и затухания сохраняют кадровую частоту.

Для разработки установите зависимости: `pnpm install --frozen-lockfile` (сохранён lockfile) или `npm install`. Редактируйте `index.html`, нужный файл в `styles/` и модули `src/`. **Не редактируйте `sudota.html` вручную:** это автоматически создаваемый файл для игры без сервера. Он не загружает скрипты или шрифты из сети.

`npm start` — сервер исходников, `npm run build` — автономный файл, `npm test` — проверки, `npm run simulate` — баланс, `npm run format` — Prettier после установки devDependencies.

## Приёмка этой версии

Финальные тесты, симуляции и проверка браузера не выполнялись по просьбе пользователя. Подготовлены профильные проверки и режим фиксированной длительности симулятора. Инструкции передачи: `reports/progression-handoff.md`. Наблюдаемый доход по ролям пока не измерен; дополнительные цены автоматически не менялись.

Нет сетевой игры, сохранения и звука. Обновление страницы начинает новый матч.
